General Information
What is Q-Guard?

Q-Guard is a powerful tool designed for automated test case generation based on actual user behaviors. It provides comprehensive test coverage by analyzing how users interact with your software.

What is a Session on Q-Guard ?

A session is a sequence of user actions performed within a specific timeframe or during a single visit to a website or application.

What is a pattern on Q-Guard?

A pattern is a sequence of action types used to model a usage and create a test case.

Features and Functionality
Does Q-Guard store any data?

No sensitive data is stored on our side. The on-premise version stores data on your servers without capturing sensitive information. The data collector anonymizes all user data directly upstream, preventing recording of each user input from the user session, retaining only user journeys. We prioritize GDPR compliance, ensuring your data privacy and security.

Does Q-Guard generate test reports?

Yes, Q-Guard generates detailed test reports. These reports provide insights into test coverage, test case results, and any identified issues. Additionally, a dashboard is available for visualizing these insights, helping you to understand the effectiveness of your testing efforts and make informed decisions.

Can I integrate Q-Guard into continuous integration (CI) workflows?

Yes, Q-Guard can be seamlessly integrated into your continuous integration workflows. It is designed to work with popular CI tools, ensuring smooth and automated testing processes.

What kind of test cases does Q-Guard generate?

Q-Guard generates automated test cases based on actual user behaviors. This ensures that the tests cover real-world scenarios, providing comprehensive coverage and enhancing the reliability of your software. 

How does Q-Guard improve test coverage?

By analyzing user behaviors, Q-Guard identifies the most critical paths and interactions within your software. This allows it to create test cases that cover a wide range of scenarios, improving overall test coverage and helping to identify potential issues more effectively.
